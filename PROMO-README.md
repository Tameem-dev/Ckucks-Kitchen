### How to use PROMO CODE ###
Navigate to Checkout: Add items to your cart and proceed to the Order Summary page

Find Promo Code Section: Look for the "Add a Promo Code" section

Enter Code: Type or paste your promo code in the input field

Click Apply: Press the "Apply" button to activate your discount

Verify Discount: The prices will update automatically to reflect your savings
